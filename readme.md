# MIMO Radar Waveform Design - A Two-Phase Encoding MIMO Radar Waveform Design Algorithm Based on LSEF [with all MATLAB codes attached]

This paper proposes an effective algorithm for designing a two-phase encoding sequence with low peak sidelobe level (PSL) for multi-input multi-output (MIMO) radar. The algorithm employs a fitness function based on logarithmic and exponential functions (LSEF) and vectorized recursive calculation methods, significantly reducing computational complexity compared to traditional methods. A two-stage search strategy effectively balances local development and global exploration. Numerical results show that the proposed algorithm has comparable PSL performance to existing algorithms under single-baseline conditions, while improving computational efficiency, and superior PSL performance in MIMO scenarios.
Introduction  
Modern radar systems encompass various applications ranging from waveform design [1], array design [2], to waveform synthesis [3], where waveform design plays a crucial role in system performance. Among various waveforms, constant modulus phase encoding sequences with low autocorrelation sidelobes and mutual correlation characteristics have become an attractive solution. Although continuous phase encoding sequences theoretically exhibit superior superior performance than their discrete counterparts, practical systems rely on digital signal processing techniques that require discrete sampling and quantization. This practical limitation prompts the development of discrete phase encoding sequences with optimized performance. Among various discrete phase encoding sequences, binary phase encoding sequences are particularly appealing due to their hardware simplicity, ease of implementation, and robust performance in practical applications.
The design problems of continuous and discrete phase coding are essentially non-convex.NP-Hard to optimize problem, Discrete cases are also constrained by their phase values. For example, the well-known Barker code[4], m-Sequence[5]And Goldmark[6]The use of mathematical theory to construct discrete phase-encoded sequences represents a traditional approach. These methods effectively generate sequences with low autocorrelation., However, there are limitations in terms of length and quantity. For example, m-The sequence exists only2− 1, ∈+Time, And has a detrimental mutual correlation property.Recent advances in continuous phase-coded waveform design, including CAN [7], -MM [8], WeBEST [9], and GD-Based [10], suggest that direct quantization could be a method for discrete phase-coded sequences. However, this quantization significantly degrades performance, especially for binary codes. The GD-based algorithm [10] achieves a peak sidelobe level (PSL) of −35 dB on a set of = 2 waveforms (each with a code length of = 1024). However, after being quantized to binary codes, the PSL worsens to only −20 dB. This results in an increase of about 10 dB in the self-correlation sidelobes and mutual correlation levels. Such significant degradation is unacceptable and could lead to missed detections.
The design algorithms for discrete phase-coded sequences mainly fall into two categories: those based on penalty and those based on heuristic search. Building on CAN [7], the algorithms CANY [11], 1bCAN [12], and 1bDI [13] introduced additional penalties to gradually guide the phase towards quasi-discrete values, albeit their solutions still require final quantization. The ITROX algorithm [14] employs alternating projections for discrete sequence design, but its SVD operations at each iteration incur high computational costs. Heuristic search-based algorithms can produce higher-order discrete phase-coded sequences, but at the cost of increased computational complexity and search duration.In [15, 16], the SHC (Shotgun Hill Climbing) algorithm is used to discover optimal or near-optimal PSL sequences for various sequence lengths. These algorithms typically employ the λ-norm as the fitness function to approximate PSL. Although this paper demonstrates that parallel search methods can effectively identify the optimal PSL within 1 second, it is important to note that these two algorithms are primarily designed for single waveform scenarios with relatively short code lengths. The author has chosen λ=4 in their formula based on experience, which effectively mitigates potential overflow issues associated with larger λ values. However, this conservative choice inevitably compromises the fidelity of the PSL approximation.In particular, recursive algorithms [17] utilize incrementally increasing recursive values to reduce optimization complexity. Most existing research focuses on single-waveform optimization, with limited studies on discrete MIMO waveform design. Notable exceptions include BiST [18] and WeBEST [9], which employ weighted metrics and approximate upper bounds of PSL for element-wise optimization, extending this more challenging domain. In MIMO-targeted algorithms, WeBEST demonstrates competitive performance through its Block Continuous Upper Sum (BSUM) paradigm. The WeBEST algorithm proves that for a set of Nt=4 waveforms, each waveform has a code length of L=256, and the PSL is −20 dB.Although this result is noteworthy, it indicates that there is still considerable potential for enhancement in sidelobe suppression.
The heuristic search algorithm, although effective, is computationally intensive. Previous work [15, 16] has achieved significant efficiency through parallel implementations, achieving optimal sequences within seconds for specific lengths. Inspired by prior research [10], this paper proposes a heuristic design algorithm for binary phase encoding sequences using the log-sumexp function (LSEF) as the fitness function. Compared to the p-norm algorithm, the LSEF algorithm has a lower complexity per iteration and has the potential to improve parallel processing efficiency. Additionally, the LSE technique can be used to prevent numerical overflow during the computation process of the p-norm algorithm.Furthermore, we have derived a vectorized recursive formula for the associated function under unit flipping, which further reduces computational overhead. Experimental results show that compared with traditional PSL algorithm, this algorithm has higher efficiency in single-base station scenario and superior PSL performance in MIMO scenario.

Conclusion
This letter proposes an efficient heuristic algorithm for the design of binary phase-encoded sequences, featuring a fitness function based on LSEF. The algorithm integrates vector recursive computation with fitness evaluation based on LSEF, significantly reducing computational complexity while maintaining optimization effectiveness. Numerical experiments demonstrate that the proposed algorithm achieves state-of-the-art PSL performance, reduces computational costs, and consistently outperforms existing algorithms in MIMO scenarios. The algorithm's efficient sequence generation capability and flexible formulation of objective functions extend its applicability from MIMO radar to integrated sensor and communication (ISAC) and array design applications. Computation efficiency is further enhanced for real-time adaptation in dynamic scenarios.
